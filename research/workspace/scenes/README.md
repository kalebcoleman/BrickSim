# Research scenes

Save future experiment scenes here under new names. The current live stage is
an upstream default-stage layer with lab content loaded; it has not yet been
saved as a self-contained research scene.

When making the first copy, verify that USD references resolve from the new
location, record the lab repository revisions, and check units, robot base and
tool frames, collision geometry, and material assignments. A saved root layer
can reference other files and is not necessarily a portable asset bundle.
